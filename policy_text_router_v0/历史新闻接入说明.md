# 历史新闻接入 v0.2

## 本阶段已经确定

- 新闻源：华尔街见闻为主源，新浪财经为补充源。
- 新闻类型：快讯与公开长文分别采集、统一保存。
- 行业口径：申万2021版二级行业。
- 数据库：PostgreSQL 16 + pgvector；Navicat、pgAdmin或DBeaver均可作为查看工具。
- 去重原则：不删除原始新闻；将相似新闻归入同一事件，分别保留最早文本和最佳分析文本。

## 已实现的入口

1. `scripts/fetch_sw2021_l2.py`：更新申万二级行业字典并输出完整性报告。
2. `scripts/probe_wallstreetcn_history.py`：按历史天数回拉华尔街见闻快讯和长文。
3. `scripts/analyze_probe_duplicates.py`：生成近重复候选簇。
4. `scripts/fetch_sina_rss.py`：获取新浪财经官方RSS的当前财经与股票新闻。
5. `sql/schema.sql`：新闻版本、事件簇、measure、routing、人工标注与行业维表。
6. `docker-compose.yml`：本地 PostgreSQL + pgvector。
7. `scripts/load_news_to_postgres.py`：幂等写入新闻；正文修改时自动产生新版本。

| 指标 | 结果 |
|---|---:|
| 快讯 | 431条 |
| 长文 | 76篇 |
| 长文/快讯 | 17.63% |
| 快讯正文中位数 | 100字 |
| 长文正文中位数 | 1563字 |
| 超过500字的长文 | 69篇 |

这说明长文数量显著少于快讯，但文本信息量更大。后续应以快讯记录首次事件时间，以长文补充复杂政策细节。

## 本地运行

更新行业字典：

```powershell
python scripts/fetch_sw2021_l2.py
```

先回拉7天做数据源探测：

```powershell
python scripts/probe_wallstreetcn_history.py --days 7 --output-dir data/history_probe/wallstreetcn_7d
python scripts/analyze_probe_duplicates.py --input-dir data/history_probe/wallstreetcn_7d
```

确认后回拉30天：

```powershell
python scripts/probe_wallstreetcn_history.py --days 30 --output-dir data/history_probe/wallstreetcn_30d
```

启动数据库前请先复制 `.env.example` 为 `.env`，并更换数据库密码：

```powershell
docker compose up -d
python scripts/init_database.py
python scripts/load_news_to_postgres.py data/history_probe/wallstreetcn_30d/flashes.jsonl data/history_probe/wallstreetcn_30d/articles.jsonl
```

## 当前边界

- 公开申万接口当前返回131个有数据的二级行业，而2021版标准参考数量为134个。程序已保留告警；正式生产前需要用团队持有的授权行业字典核对缺失项。
- 当前近重复算法用于产生候选，不直接删除或合并新闻；跨来源事件最终还要结合时间、发布机构和向量相似度判断。
- 新浪RSS适合实时更新，历史回拉入口仍需单独验证。
- 不抓取或绕过付费正文；付费文章只保存公开元数据和公开摘要。
