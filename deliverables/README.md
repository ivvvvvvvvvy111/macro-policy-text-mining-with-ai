# deliverables

## 长文政策因子最终报告（2026-08-17）

- `长文政策因子最终报告/index.html`：4,873条长文终版的自包含交互式报告，可直接发送给同事，无需数据库或联网加载图表资源。
- 明确区分政策因子、中证全指和全A等权；包含全A/风格/行业的中间评分维度、跳变日期真实新闻和Pearson白话解释。
- 行业支持选择项目字典中的全部131个申万2021二级行业、切换已落盘市场基准和拖动时间范围；未可靠落盘的申万行业指数与沪深300明确标为待接入。
- 可复现构建命令：`make calendar-report`。

本目录存放面向研究人员的可审阅交付物，不是模型原始输出目录。

主要交付：
- `结果展示网页/index.html`：单文件HTML，展示Prompt链路、统计、真实案例和最终分数；可直接发送给同事。
- `评分标准展示网页/index.html`：候选新版评分标准，展示统一正交骨架、三条路线逐分锚点与真实新闻示例。
- `新版评分Prompt展示网页/index.html`：三套候选v2评分Prompt的可折叠、可复制单文件HTML。
- `政策评分方法综合报告/index.html`：合并小样本结果、维度优化、新旧Prompt对比和下一步事项的最终单文件HTML。
- `政策新闻到评分_15条案例Notebook.md`：按输入、拆分、路由、评分展开的15条案例。
- `政策新闻信息提取全流程报告.md`：简洁的数据结构与处理流程报告。
- `政策新闻全链路审阅表.xlsx`：全量人工审阅工作簿，本地交付使用，不进入Git。

生成脚本位于 `tools/`。预览图、构建日志、巨型JSON和工作簿检查文件属于临时产物，不应发布到GitHub。
