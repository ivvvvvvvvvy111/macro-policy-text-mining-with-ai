# 政策新闻信息提取全流程报告

## 1. 当前数据与项目结构

项目先按来源采集新闻，再形成统一事件与模型结果。`state/*.sqlite3` 是各来源的采集状态库：`records` 保存标题、正文、链接、发布时间、正文状态及原始载荷，`checkpoints` 保存采集游标，`collection_errors` 保存采集错误。`postgres_data/` 对应统一 PostgreSQL 库，设计表包括：

- 来源与采集：`sources`、`ingestion_runs`、`news_items`、`news_versions`。
- 去重与事件：`event_clusters`、`event_members`、`news_embeddings`。
- 模型与版本：`prompt_versions`、`model_runs`。
- 研究结果：`measures`、`routing_results`、`routing_industries`、`human_annotations`。

本次交付不重新调用模型，直接使用 `work_scoring_v1/data/sample_5000.csv` 和现有输出。5,000 条新闻中，1,309 条已有措施拆分输出；形成 5,527 条措施路由记录和 18,111 条评分关系，其中行业 15,885 条、全A 1,808 条、风格 418 条。

## 2. 一条新闻如何变成评分

处理链路是：**新闻正文 → 最小措施 → 三路线分类 → 关系级评分 → 日频面板**。

以 2024-04-12《[关于严格执行退市制度的意见](https://www.gov.cn/zhengce/zhengceku/202404/content_6945065.htm)》中的措施 M001 为例：

1. **原始新闻**：全文包含重大违法强制退市、规范类退市、交易类退市及执行机制等多项内容。
2. **措施拆分提示词**：要求政策工具、对象、执行时间或直接机制不同时拆分；证据必须是连续原文。模型将其中一项输出为“科学设置重大违法强制退市适用范围，打击财务造假”，并保留政策动作、对象、机制和原文证据。
3. **路由提示词**：三个标签可重叠，但必须存在直接、可解释的传导。该措施被判为 `all_a=true`、`style=true`、`industry=false`，主路由为 `multiple`，置信度 0.95。理由是退市制度改变全市场治理环境，同时对高质量与低质量、不同风险和流动性特征的公司产生相对差异，但未直接改变某一行业的经营变量。
4. **全A评分提示词**：按“措施 × 渠道 × 期限”展开，得到公司治理、股票供给、预期协调、监管风险等关系；每条关系分别给出方向、强度、覆盖、确定性、持续性、信息增量和置信度。
5. **风格评分提示词**：先识别渠道，再映射到风格轴。该措施形成 `quality`、`risk` 等关系，例如公司治理渠道下质量轴方向为 +1，表示高质量端相对占优。
6. **结果落表**：新闻总览保留整篇正文；措施表展示 M001 的拆分与路由；评分表逐行展示 R001、R002……的维度得分、证据和理由，可完整回溯。

五份实际提示词全文已放入 Excel 的“提示词全文”工作表，避免报告重复粘贴长文本。

## 3. 三条路线的典型结果

### 全A

- 《平安钟正生：还有哪些增量政策可以期待？》M004：全国商业性个人住房贷款最低首付比例统一至 15%。模型识别为全A、行业、风格三路线，主要全A渠道包括增量资金和预期协调。
- 《住建部主管媒体：居民购房压力大幅缓解》M005：取消全国层面房贷利率下限。模型同时识别融资条件、房地产和银行行业传导，以及成长价值、大小盘等相对差异。
- 同一新闻 M006：保障性住房再贷款支持收购存量商品房。模型识别央行资金供给、房地产去库存及头部房企相对受益。

### 风格

- 《关于严格执行退市制度的意见》M001：财务造假强制退市，主要映射到质量、风险和流动性风格。
- 同一文件 M003：加大绩差公司退市力度，模型给出质量端 +1、大小盘轴偏大盘端以及风险轴偏低风险端的相对关系。
- 《亮点“绝不仅仅”四方面——财政部新闻发布会解读》M002：特别国债补充国有大行核心一级资本，模型识别大盘、高股息及国有大行相对差异。

### 行业

- 《电力装备行业稳增长工作方案》M007：落实所得税抵扣、研发加计扣除等优惠，按成本和技术渠道映射到电机、光伏等申万二级行业。
- 《推动商务信用体系建设高质量发展的指导意见》M002：增加汽车、家电消费信贷支持，按需求和价格渠道映射到乘用车、白色家电和黑色家电。
- 《安全应急装备重点领域发展行动计划》M005：支持龙头企业担任链主并推进数字化转型，按供给和技术渠道映射到工程机械、风电和光伏设备。

### 同时符合全A、行业与风格

住房首付比例统一、取消房贷利率下限、保障房再贷款三类措施均被模型路由至三条路线。它们分别改变宏观融资或流动性环境，对房地产及金融行业产生直接经营传导，并可能造成高杠杆/低杠杆、成长/价值、大小盘之间的相对差异。此类多路线结果最需要人工复核，避免把房地产行业影响过度外推为全市场或风格效应。

## 4. 质量情况

- `errors.jsonl` 有 3,763 行，涉及 3,722 个唯一新闻；同一新闻可能因多次重试产生多行。
- 5,000 条新闻的最终状态为：901 条完成全链路，404 条判定为非政策新闻，3 条已路由但没有评分关系，1 条已拆分但路由缺失，3,691 条没有拆分结果并有模型错误。
- 运行摘要中的 3,691 与错误日志 3,763 并不矛盾：前者是无拆分结果的新闻数口径，后者包含重复重试日志。
- `policy_delta`、`novelty` 当前按设计为空；由此依赖历史比较基准的新闻分或 surprise 指标不能当作 0 使用。

## 5. 建议继续完成的工作

1. 优先重跑 3,691 条无拆分结果的新闻，并把解析错误、服务端错误和限流错误分开治理。
2. 建立分层人工金标准集，分别检验措施边界、三路线分类、申万行业标签和评分维度；多路线措施应提高抽检比例。
3. 重点检查行业路由是否过宽。目前行业关系占比 87.7%，且部分措施一次关联多个行业，存在把间接传导当直接传导的风险。
4. 扩充风格有效样本并明确风格轴方向解释，避免将行业内部涨跌误判为风格差异。
5. 建立同类政策的历史基准与版本链，之后再计算政策变化、新颖度、新闻分和 surprise。
6. 因子正式使用前完成重复新闻、时点一致性、来源偏差、前视偏差及样本外稳健性检验。
