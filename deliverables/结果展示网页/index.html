政策新闻 → 可解释评分

从一篇政策新闻出发，展示它如何被拆成最小措施、路由到全A/风格/行业，并形成可追溯的关系级分数。

原始新闻如何经过 Prompt 变成分数

前四步由大语言模型阅读文本并按 Prompt 输出结构化判断；最后一步由程序执行固定公式。也就是说，模型不直接随意给出最终综合分。

AI + Prompt 判断程序固定公式
01 原始数据

政策新闻全文

标题、日期、来源、URL、正文和内容状态。

没有打分；这里只是读取数据库或冻结样本。
02 Prompt ①

措施拆分

判断是否为政策新闻，并拆成最小独立措施。

Qwen3.5-9B
输出：summary、action、target、mechanism、evidence
03 Prompt ②

三路分类

判断措施进入全A、风格、行业中的哪些模块。

Qwen3.5-9B
输出：三个布尔标签、行业、风格维度、置信度和理由
04 Prompt ③

分路线评分

按实际路由调用全A、风格和/或行业评分 Prompt。

Qwen3.5-35B-A3B
模型输出：方向、强度、覆盖、确定性、持续性、置信度等原始维度分
05 固定规则

计算最终分数

Python 公式把维度分组合为 state_score 或 a_unit。

不是 Prompt，不是模型再打分
输出关系级长表，并按期限做日频衰减聚合。
最终分数如何算行业 state_score = direction × intensity/4 × coverage/4 × certainty/4 × (0.5 + 0.5 × persistence/4)全A state_score = direction × intensity/4 × coverage/4 × certainty/4 × persistence/4 × confidence风格 a_unit = direction × relative_strength/4 × coverage/4 × certainty/4 × confidence

其中方向、强度等维度由评分 Prompt 约束下的大模型判断；乘法公式由代码固定执行。confidence 是判断把握度，不是政策强度。
