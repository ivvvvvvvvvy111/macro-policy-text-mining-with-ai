# 因子与市场基准口径

## 三类对象
- 全A政策因子：政策评分关系经期限衰减后，先按8个渠道聚合，再按`1/8`合成的政策温度；它不是收益率。
- 中证全指：代码`000985.CSI`的外部宽基市场指数，日收益为`close_t / close_(t-1) - 1`。
- 全A等权：每日对全部有效A股个股涨跌幅做简单平均，再以`cum_t=∏(1+r_t)-1`复利；为项目研究构造，不是官方指数，也不是政策因子。

## 因子口径
- 原始政策温度：保留当日活跃政策数量影响，适合衡量政策总压力/支持度。
- 每新闻归一温度：`原始温度 / 活跃新闻数`，用于检查结果是否只是被新闻数量驱动；不是当前生产基线。
- Z值：在当前样本内做`(x-样本均值)/样本标准差`，用于画图比较尺度，不改变底层关系分。

## 行业市场基准
- 申万二级行业政策因子与申万行业市场指数是两类数据，前者来自政策文本，后者来自市场价格。
- 申万行业指数并不等于行业成分股简单等权。
- 若构造行业等权收益，必须使用每个历史交易日当时有效的行业成分股，对有效个股收益简单平均；不能用当前成分股回填历史，否则存在前视/幸存者偏差。

## 时间与缺失
- 当前长文日历样本窗口为2024-08-01至2026-01-31。
- 2024-08-01以前没有进入本轮样本，不能解释为因子为0。
- 评分维度日均值仅在当天存在有效关系时计算；空值不是0。
