## 一、当前理解

### 1.1 课题定位

子课题 1 的作用对象是**全A 市场的多空与仓位**，以及 A 股两组风格（**大小盘**、**成长/价值**）。产出为：

- **仓位信号 / 市场温度**：指导全A 加仓、减仓或中性
- **风格切换信号**：指导大小盘、成长/价值相对强弱

Review05 给的「市场定位表态 + 制度路径 + 资金通道」三档识别，以及监管收紧作为负向触发，是**头脑风暴初稿**，不是最终维度表；本综述从文献中重新归纳可打分的 LLM 维度。

### 1.2 因子/指标形态

| 项目 | 本子课题 |
|------|----------|
| 因子形态 | **全市场仓位 + 风格相对强弱信号**（非个股截面因子） |
| 研究单元 | 单篇政策/制度/监管文本 → 窗口聚合为**市场-日/周**指数 |
| 可获得口径 | 媒体发布日 / 交易所公告日 / 官方通稿日（非事件发生日） |
| 与子课题 2 边界 | ② 行业产业看申万行业；① 只看**全A + 风格轴**，行业政策仅当影响全市场或风格时纳入 |
| 与⑤ 边界 | ⑤ 货币流动性看央行货政/例会；① 可借鉴其方法论，但主文本源为**资本市场制度类** |

### 1.3 与机构调研 17 维、政策宏观维度的差异

| 对比项 | 机构调研 LLM | 政策宏观 LLM（师兄范本） | **子课题 1** |
|--------|-------------|-------------------------|-------------|
| 文本 | 公司 Q&A | 政策/新闻/央行 | 资本市场制度/监管/论坛表态 |
| 颗粒度 | 股票-日 | industry_asset_tags | **全A + 风格轴** |
| 主输出 | 17 维个股因子 | 宏观状态/政策信号/EPU | 仓位温度 + 风格切换 |
| 索引层 | 热点清单 | 行业/资产映射 | **文本类型 + 监管工具 + 信息影响力** |

## 三、比较有用的研报与文献（精读）

### 3.1 维度设计类启发

#### （1）Baker, Bloom, Davis & Kost — Policy News and Stock Market Volatility（EMV）

原文链接：[NBER w25720](https://www.nber.org/papers/w25720) | 数据：[EMV_monthly](https://www.policyuncertainty.com/EMV_monthly.html)

##### 3.1.1 原文做了什么

用美国 11 家大报构建**股票市场波动（EMV）**指数（与 VIX 样本外相关约 0.8），再在 EMV 文章池内拆约 40 类「驱动波动的议题」，其中**政策类**占比较高：财政/税收 35%、货币政策 30%、**监管 25%**。

##### 3.1.2 对本项目的启发

| 启发 | 内容 |
|------|------|
| 维度启发 | 先定义「与**股市波动/全A风险**相关的文本池」，再分类；监管/制度/财政通道应作**分项指数** |
| 聚合启发 | 分项 EMV(c) = 类别占比 × 总 EMV；类比：**监管约束指数 = 监管类文本占比 × 总政策冲击** |
| 验证启发 | 总指数→VIX；分项→对应资产波动；子课题1：总指数→中证全指/300 波动或收益，分项→风格指数 |
| 适用性 | **很有用**；非 LLM，但「先池后类」逻辑应保留；A 股需换中文词表或 LLM 标签 |

#### （2）CAPC-CG — 中国自适应政策沟通语料

原文链接：[arXiv:2510.08986](https://arxiv.org/abs/2510.08986)

##### 3.2.1 原文做了什么

将中央政策段落标注为 **B 授权支持 / R 禁止约束 / Y 执行压力 / C 试点灵活 / G 模糊空间**，人工+模型一致性高（W/R/N 准确率约 0.91）。

##### 3.2.2 对本项目的启发

| 启发 | 内容 |
|------|------|
| 维度启发 | **态度 vs 路径**：「鼓励中长期资金入市」= B；「严厉打击造假」= R/Y；「研究推出」= G |
| 映射 | 对应 Review05 三档：**定位表态**（B/G）、**制度路径**（Y/C 有工具时）、**监管负向**（R） |
| 适用性 | **很有用**；资本市场通稿可直接迁移语气层；需叠加「资金通道/交易制度」专用维度 |

#### （3）PMC 指数 + 城市更新「工具×发力点×目标」

原文链接：[PMC arXiv:2409.12831](https://arxiv.org/abs/2409.12831)

##### 3.3.1 原文做了什么

PMC 把政策质量拆成 10 类一级变量（政策性质、时效、领域、来源、激励保障、功能、操作层级、对象、效力、透明度），0/1 编码后聚合；城市更新文献补充**工具×发力点×目标**三维。

##### 3.3.2 对本项目的启发

| 启发 | 内容 |
|------|------|
| 维度启发 | **政策执行确定性**（主体、工具、期限、考核）；**政策发力点**（融资端/制度端/资金端） |
| 映射 | 「制度路径+资金通道」：储架发行/分红指引 = 制度+资金双发力 |
| 适用性 | **有用**；更适合「有明确条款」的交易所规则；对论坛口号式表述需降权 |

#### （4）姜富伟等 (2021) — 央行货政报告文本→股市

本地 PDF：`文献综述/央行货币政策报告文本信息、宏观经济与股票市场.pdf`（待补）

##### 3.4.1 原文做了什么

从 71 期货政报告提取 **tone / similarity / readability**；EGARCH 显示 **tone→收益、similarity→波动**；**仅「央行指引」部分**驱动股市，「基本面回顾」不显著。

##### 3.4.2 对本项目的启发

| 启发 | 内容 |
|------|------|
| 维度启发 | **文本相似度/重复度** → 全A **波动/温度**；**前瞻指引类表述** → **仓位方向** |
| 分解启发 | 资本市场政策也要分：**可执行制度变更** vs **背景表态/成就复述** |
| 验证启发 | EGARCH 均值/方差分工 → 子课题1：仓位维度检验收益，EPU/监管维度检验波动 |
| 适用性 | **方法论很有用**；文本对象偏央行，⑤子课题主用；①仅借鉴分解与验证 |

#### （5）国信 田地 — AI赋能资产配置(七)：DeepSeek理解货币政策取向

本地 PDF：`文献综述/20250317-国信证券：AI赋能资产配置(七)...pdf`（待补）| 摘要见 [`文献_raw.md`](文献_raw.md) [006]

##### 3.5.1 原文做了什么

五维框架（基调/工具/降准降息/利率/外汇）+ **AI半自动**（历史文本↔力度指数对照）优于全自动；文本选择四要求：定期、范式固定、情绪分明、有影响力。

##### 3.5.2 对本项目的启发

| 启发 | 内容 |
|------|------|
| Prompt启发 | **半自动 > 全自动**；应投喂「分析师框架 + 历史对照样本」 |
| 文本筛选 | 陆家嘴论坛、交易所制度通稿、证监会发布会符合「范式固定、有影响力」 |
| 适用性 | **很有用**；维度需改写为资本市场五维（见 §4.3 Prompt） |

#### （6）申万宏源 — 大模型赋能情绪、政策指标构建（2025-04-07）

本地抽取：[`20250407-申万宏源...txt`](../../宏观政策文本/tmp/pdf_extract/20250407-申万宏源：大模型赋能情绪、政策指标构建――AI辅助投研深度案例系列之二.txt)

##### 3.6.1 原文做了什么

用 DeepSeek-R1 + Prompt（角色= A股策略分析师）从新闻/政策推断**月度全A多空**；与价量情绪结构指标合成后择时；结论：**分档打分比精确连续值更稳**；信息源有限、存在「讨好型」偏差。

##### 3.6.2 对本项目的启发

| 启发 | 内容 |
|------|------|
| 产出形态 | 与子课题1一致：**全A多空/仓位**；可扩展第二输出为**风格偏多（成长/小盘）** |
| 负面教训 | 不要用开放域联网搜索代替可控语料；必须**固定来源 + 前向数据隔离** |
| 适用性 | **高度有用**；是全A级 LLM 文本因子的国内券商样板 |

#### （7）长江证券 — 五维度模型·医药政策及事件（2020-05-08）

本地 PDF：[`0709-文献raw.md/20200509-长江证券：长江金工基本面量化五维度模型应用之医药篇：量化解剖行业政策及事件.pdf`](../0709-文献raw.md/20200509-长江证券：长江金工基本面量化五维度模型应用之医药篇：量化解剖行业政策及事件.pdf) | 第二轮 raw：[004]

##### 3.7.1 原文做了什么

长江金工「基本面量化五维度」系列的**政策篇**（上篇已做宏观/中观/风格三维景气打分）。本篇专门补第四维「**政策及事件**」，解决痛点：**行业政策条目多、区域差异化、与宏观景气交织**，纯景气模型挡不住政策冲击（如 2018 H2）。

**五维度框架（系列定位）：**

| 维度 | 本篇 | 说明 |
|------|------|------|
| 宏观 | 上篇 | GDP、流动性等 |
| 中观 | 上篇 | 行业景气指标 |
| 市场风格 | 上篇 | 风格因子 |
| **政策及事件** | **本篇核心** | 官方文件 + 社会负面事件 |
| 行业比较 / 资金流 | 后续 | 北上、ETF 申赎等 |

**政策分类（逻辑先于打分）：**

1. **按影响深度**
   - **结构性/主线级**：改变行业分析逻辑（如 2009–2011 新医改：支付扩容「沉淀」→ 医保压力「分化」）
   - **交易性/高频级**：不改长期逻辑，但引发股价波动（各地细则、征求意见稿、试点扩围）

2. **按政策主线（表 1）**
   - **控费降价**：安徽模式、限抗令、一致性评价、两票制、带量采购、辅助用药限制、高值耗材集采……
   - **鼓励创新**：审评审批改革、MAH、优先审评、ICH、创新激励……

3. **三条判断原则（可写入 Prompt）**
   - **全国推广 > 区域试点**（安徽本地试点影响小；56 号文全国推广才引发板块回撤）
   - **首次推出 > 后续推进**（2018「4+7」冲击大，2020 第二轮明显衰减）
   - **实际落地 > 意见稿/指导意见**（铺垫期 market 已部分 price in）

**事件研究标定：** 以政策发布日/开标日为事件点，相对 Wind 全 A 超额收益，考察前后 3 个月、12 周窗口，输出**影响周期 T**、**最大幅度 A**、子行业分化。

| 典型事件 | 发现 |
|----------|------|
| 2009 安徽基药（地方） | 几乎无板块反应 |
| 2010「56 号文」全国推广 | ~**30 交易日**回撤；医药商业最弱 |
| 2012 基药招采落地 | ~**1 周**反应——预期已消化 |
| 2018-12「4+7」带量采购 | 平均降幅 52%、最大超 90% → ~**1 个月**回撤；生物制品/化学制剂/器械最弱 |
| 2020-01 第二轮带量采购 | 周期与幅度**弱于**第一轮 |

**表 8 打分规则（核心，周频更新）：**

| 类型 | 政策/事件性质 | 影响周期 | 幅度与衰减 |
|------|--------------|----------|------------|
| 政策·控费/创新 | 纲领性、指示性意见/公告 | ~**1 周** | **-4~+4**；4 周周期例：第 1–4 周 **4/3/2/1**（负向同理） |
| 政策 | 前序政策延续 | ~**1 周** | 幅度通常更小 |
| 政策 | 实质性、超预期落地 | **2–4 周** | 同上递减 |
| 事件 | 权重股个股负面 | ~1 周 | 主要冲击子行业 |
| 事件 | 行业级重大负面（如长生疫苗） | ~**4 周** | 全社会影响 |
| 事件 | 传染性疾病 | 视持续时间 | 宏观冲击 + 板块结构性 |

**三条运行规律：** ① 影响有累积，非一日消化；② 短期常**全板块同向**，中长期才分子行业；③ **同类政策后续衰减**（4+7 vs 第二轮集采）。

**回测（表 9–10）：** 2010–2020 重点负面政策/事件按表 8 周频打分；事件下一交易日起按影响周期**空仓 1–4 周**。

| 策略 | 年化收益 | 夏普 | 最大回撤 |
|------|----------|------|----------|
| 医药指数 | 14.52% | 0.56 | 53.51% |
| 排除政策/事件冲击窗口 | **26.13%** | **1.06** | 32.03% |

超额 **+11.61%**。结合上篇：宏观+中观+风格 alone 难避 2018 H2；**政策维是景气模型缺的关键一块**。

### 5.4 维度边界试打分（Review05 五条原文）

> 目的：检验维度是否可区分（Hansen 标签可分离性思路）。**非最终 LLM 输出，为人工逻辑试表。**

| 原文事件 | 应触发维度（主） | 不应高估维度 | 全A仓位 | 风格倾向 |
|----------|------------------|--------------|---------|----------|
| 陆家嘴吴清演讲（科创/外资/储架） | 市场定位↑、制度确定性↑、资金通道↑、成长价值↑ | 监管约束（除非同文有整治） | 偏多 | 成长>价值；大盘略偏（外资） |
| 稳外资15条（QFII/算力半导体） | 资金通道↑↑、市场定位↑ | 大小盘（不单边小盘） | 偏多 | 成长（算力/半导体） |
| 分红回购指引 | 资金通道↑、成长价值↓（价值/红利） | 交易制度变更 | 温和偏多 | **价值/红利** |
| ST涨跌幅 5%→10%、做市 | **交易制度变更↑**、大小盘↑（小盘/反转） | 资金通道 | 中性 | **小盘/反转** |
| 八部门跨境整治 | **监管约束↑↑**、风险偏好↓ | 资金通道、成长偏好 | **偏空/降仓** | 防御、大盘 |
| 财务造假协同执法 | 监管约束↑、风险偏好↓、EPU(监管)↑ | 市场定位（若未同时释呵护政策） | 偏空 | 小盘/题材承压 |

**边界测试结论：**

1. 「资金通道」与「成长价值」可区分：稳外资偏成长，分红指引偏价值。
2. 「交易制度」必须独立：ST 涨跌幅几乎不影响全A仓位，但显著影响大小盘。
3. 「监管约束」是负向主轴：与「市场定位」可同文并存（需分维度独立打分）。
4. 子课题 2 行业政策（如七部委新型工业化）**不应**在子课题 1 主样本中抢权重——若分类层误路由，应在索引层剔除。

## 六、提示词设计要点

### 6.1 通用原则（8 条）

1. 先摘录 `evidence`，再评分；证据必须来自原文。
2. 未涉及维度 → `score=0` 或空，不强行联想。
3. 各维度**独立判断**；同一文本可「定位呵护 + 监管收紧」并存。
4. 不硬套固定档位；说明正负向即可。
5. 不引入原文外信息；必要时遮蔽具体公司名。
6. 固定 JSON 输出；`temperature=0~0.3`。
7. **官方套话 ≠ 强利好**；须有工具、对象、期限、数字证据。
8. 分档打分优先于伪精确连续值（申万结论）。
9. **落地 > 意见稿；全国 > 区域；首次 > 后续**（长江三原则）。
10. 须标注 `doc_type`、`policy_tier`、`impact_weeks`；聚合用周频衰减，非简单日频均值。

### 6.2 输入粒度与日期

| 字段 | 说明 |
|------|------|
| 输入单位 | 单篇政策/制度/通稿/快讯（标题+正文） |
| `available_date` | 媒体发布日或交易所公告日 |
| 聚合 | 同一交易日多篇 → 加权均值/低分占比/边际变化 |
| 来源 | 新华社、央视财经、交易所、证监会、财联社等（白名单） |

### 6.3 输出字段（最小集）

```text
text_type          多标签：定位/制度/资金/监管/论坛
info_influence     0-5
doc_type           纲领/意见稿/落地细则/延续解读
policy_tier        全国/部委/区域/交易所
is_first_release   true/false
impact_weeks       1-4
dimension          与 §5.2 一致
score              按口径
evidence           原文短句
reason             一句话
confidence         0-1
model / prompt_version
```

### 6.4 可跑 Prompt 骨架（v0.1）
