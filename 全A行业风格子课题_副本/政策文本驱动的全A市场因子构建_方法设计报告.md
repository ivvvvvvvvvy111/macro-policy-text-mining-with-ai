# 政策文本驱动的全A市场因子构建：直接评分、渠道拆分与市场温度聚合

用途：说明资本市场政策、制度、监管和资金类文本如何转化为全A市场层面的政策信号，并形成“日期 × 全A政策指标”的因子面板。本文与行业、风格方案使用同一套“文件—措施—关系—评分—聚合”母框架，但最终只回答一个问题：政策是否改变了整个A股市场的资金、交易、治理和风险环境。

写法：本文为方法设计版。先明确全A子课题与行业、风格子课题的边界，再说明文本筛选、措施拆分、全市场传导渠道、评分标准、时间结构、聚合方法、LLM输出和检验方案。正文使用一份虚构政策作为贯穿案例，所有分数只展示数据形状。

口径：LLM负责事实抽取、措施拆分、渠道识别和规则化评分，不直接给出投资结论。方向、强度、覆盖、执行确定性、新颖性和持续性是事件级结构化信息；渠道权重、时间衰减、总分公式和仓位映射必须通过历史样本检验。

## 一、当前理解与核心结论

全A直接打分研究解决的是“这项政策对A股整体环境偏正面、偏负面还是没有全市场影响”，不是“利好哪个行业”或“哪类风格相对占优”。第一版建议采用以下结构：

```text
原始政策文本
→ 拆分政策措施
→ 判断是否具有全市场影响
→ 展开全市场传导渠道
→ 按渠道和影响期限直接评分
→ 形成事件级全A向量
→ 按日期衰减聚合
→ 得到全A政策温度、正负冲击、分歧度和关注度指标
```

核心结论有六点：

1. 全A方案可以直接评分，但不宜把整篇文件压成一个分数。最小评分单元应为`政策措施 × 全市场传导渠道 × 影响期限`。
2. “全A影响”必须先通过路由判断。只影响单一产业的政策进入行业管线；只造成不同股票特征分化的政策进入风格管线；影响多数股票共同交易环境的政策才进入全A主链。
3. 同一措施可以通过多个渠道产生相反作用。例如强化退市和造假监管，短期可能压低风险偏好，长期可能改善市场质量，两条关系必须分别保存。
4. 方向与强度分开。方向只表示正、负或明确中性；强度、覆盖范围、执行确定性和信息增量决定事件幅度；持续性和起效速度决定时间路径。
5. 第一版不只保留“净温度”。正向冲击、负向冲击、净温度、渠道分项、政策分歧度和政策关注度应同时入库，避免正负抵消后丢失信息。
6. LLM输出是事件级原材料。全A仓位信号属于策略层结果，必须在事件研究、时序检验和样本外回测后再定义。

## 二、全A与行业、风格子课题的边界

三类直接政策文本可以接收同一篇文件，但观察对象、最小单元和最终产出不同。

| 子课题 | 核心问题 | 最小观察单位 | 最终产出 |
|---|---|---|---|
| 行业 | 政策影响哪个行业，以及通过需求、成本、供给等什么经营渠道影响 | 措施 × 行业对象 × 作用渠道 | 行业 × 日期 × 政策指标 |
| 全A | 政策是否改变整个A股共同面对的资金、交易、治理和风险环境 | 措施 × 全市场渠道 × 期限 | 日期 × 全A政策指标 |
| 风格 | 政策对不同类型股票的影响是否不对称 | 措施 × 渠道 × 风格轴 × 期限 | 日期 × 风格轴因子 |

### 2.1 路由规则

建议按以下顺序判断：

1. 原文是否包含可独立识别的政策动作，而不是行情复述、一般性讲话或重复转载；
2. 该动作是否改变多数A股共同面对的市场变量；
3. 如果主要影响行业经营变量，转入行业管线；
4. 如果主要影响公司特征之间的相对收益，转入风格管线；
5. 一篇政策可以同时进入多条管线，但每条管线只保存本课题对应的关系。

### 2.2 边界示例

| 政策示例 | 行业 | 全A | 风格 | 说明 |
|---|---:|---:|---:|---|
| 全市场降低印花税 | 弱 | 强 | 可能弱 | 直接改变全市场交易成本 |
| 引导中长期资金入市 | 弱 | 强 | 可能偏大盘、价值 | 先形成全A资金信号，再另做风格映射 |
| 新能源汽车消费补贴 | 强 | 弱 | 可能偏成长 | 主要改变产业需求，不应抢占全A权重 |
| 放宽科技企业上市门槛 | 弱 | 中 | 强 | 既改变股票供给，也造成成长风格分化 |
| 强化财务造假和退市执法 | 弱 | 强 | 强 | 短期风险偏好与长期市场质量均受影响 |
| 单一地区产业园扶持 | 强 | 弱 | 弱 | 覆盖不足以代表全市场 |

## 三、步骤0：原始文本、可获得时间与去重

### 3.1 文件层字段

| 字段 | 说明 |
|---|---|
| `policy_id` | 政策文件唯一编号 |
| `title` | 标题 |
| `source` | 发布机构或首发媒体 |
| `source_type` | 官方原文、权威媒体、一般媒体、卖方解读 |
| `publish_time` | 首次公开时间，保留时分秒 |
| `available_date` | 回测可使用的首个交易日 |
| `policy_tier` | 全国、部委、交易所、区域 |
| `doc_stage` | 表态、征求意见、正式规则、落地细则、执行通报、解读 |
| `full_text` | 清洗后的正文 |
| `duplicate_group_id` | 同一事件的原文、转载和解读归组编号 |
| `model_version` | 模型版本 |
| `prompt_version` | Prompt与评分规则版本 |

### 3.2 时间口径

- 使用市场首次能够获得的信息时间，不能使用数据库抓取日替代首发日；
- 交易日收盘后发布的文本，原则上从下一交易日进入回测；
- 后续细则不能倒填到首次表态日；
- 同一政策的官方原文、媒体转载和卖方解读先归组，不机械累计三次信号；
- 卖方解读如纳入，应与官方原文分开保存来源权重，不能反向污染原文评分。

## 四、步骤1：将政策文件拆分为措施

一篇文件常同时包含资金支持、制度改革和监管约束。整篇评分会把这些方向不同的动作相互抵消，因此先拆成可以独立判断的政策措施。

### 4.1 拆分标准

满足以下任一条件时应拆成新措施：

- 政策工具不同；
- 作用对象不同；
- 生效时间或持续期限不同；
- 传导渠道不同；
- 一项为支持、另一项为约束；
- 一项是原则表态、另一项是正式落地。

### 4.2 措施表

| 字段 | 说明 |
|---|---|
| `measure_id` | 措施唯一编号 |
| `policy_id` | 所属文件 |
| `measure_summary` | 不带评价的措施摘要 |
| `policy_action` | 降费、增资、开放、收紧、执法、托底、改革等固定标签 |
| `target_scope` | 全市场、特定板块、特定主体 |
| `effective_date` | 正式生效日；未知则为空 |
| `evidence` | 原文证据句 |

## 五、步骤2A：判断是否进入全A管线

### 5.1 全市场性不是情绪判断

全市场性回答的是“影响对象是否足够广”，不是“政策是否重要”。一项金额很大的行业补贴仍可能不是全A政策；一项金额不大的交易规则调整却可能覆盖全部股票。

### 5.2 建议的路由字段

| 字段 | 取值 | 作用 |
|---|---|---|
| `market_wide_relevance` | 是、否、条件成立时是 | 是否改变共同市场环境 |
| `affected_market_scope` | 全A、主要板块、局部板块、单一行业 | 描述覆盖层级 |
| `route_to_all_a` | `true/false` | 是否进入全A评分主链 |
| `route_to_industry` | `true/false` | 是否同时进入行业管线 |
| `route_to_style` | `true/false` | 是否同时进入风格管线 |
| `route_reason` | 文本 | 路由理由与证据 |

仅有“促进资本市场高质量发展”等一般性措辞、但没有新增政策动作时，可以保留为文本记录，不进入全A事件评分。

## 六、步骤2B：全市场传导渠道

全A渠道回答“这项措施首先改变了市场的什么共同变量”。第一版建议保留八类渠道。

| 渠道 | 核心问题 | 典型政策例子 | 正向作用示例 | 负向作用示例 |
|---|---|---|---|---|
| 市场托底与政策定位 | 是否明确稳定、呵护或压制资本市场 | 宣布使用稳市资金增持宽基ETF，或明确提出维护资本市场稳定 | 稳市工具、明确托底、提升市场战略定位 | 明确降温、限制市场功能 |
| 增量资金与配置需求 | 是否增加可进入A股的资金或持股需求 | 引导保险、养老金提高权益配置比例；设立回购增持支持工具 | 长期资金、外资准入、回购增持 | 资金退出、配置限制、减持压力 |
| 交易成本与市场流动性 | 是否改变交易摩擦、成交深度和可交易性 | 下调股票交易印花税；降低交易经手费；扩大做市机制 | 降低税费、优化做市、改善互联互通 | 提高交易成本、限制交易或流动性 |
| 融资与股票供给 | 是否改变IPO、再融资、减持和股份供给 | 调整IPO节奏、再融资门槛或股东减持规则 | 融资功能改善可支持长期市场发展 | 短期股票供给扩张、稀释和承接压力 |
| 公司治理与市场质量 | 是否改善信息披露、投资者保护和劣质公司退出 | 强化财务造假处罚、特别代表人诉讼、退市执行 | 打击造假、加强赔偿、提高上市公司质量 | 规则执行成本上升或短期风险暴露 |
| 监管约束与风险承担 | 是否提高处罚、杠杆、交易或合规约束 | 收紧融资保证金比例；打击异常交易、题材炒作和量化违规 | 长期降低尾部风险 | 短期风险偏好下降、活跃资金收缩 |
| 制度开放与市场可达性 | 是否扩展投资者、产品和跨境参与范围 | 扩大互联互通标的；放宽QFII准入；新增跨境投资产品 | QFII、互联互通、产品扩容 | 准入收紧、跨境限制 |
| 不确定性与预期协调 | 是否降低规则不确定性、稳定预期 | 正式公布新规的对象、比例、生效日、过渡期和执行部门 | 明确工具、对象、时间和执行路径 | 政策反复、规则模糊、超预期收紧 |

### 6.1 渠道边界

- “市场托底”关注政策方向和稳市承诺，“增量资金”必须有资金来源或配置机制；
- “交易成本”关注交易摩擦，“融资与股票供给”关注市场需要承接的股份数量；
- “公司治理”允许长期正向，“监管约束”允许短期负向，同一措施可以同时生成两条关系；
- “制度开放”强调参与边界，“不确定性”强调信息是否清晰和稳定；
- 渠道标签本身不带固定正负号，方向必须结合具体措施与期限判断。

### 6.2 与既有全A候选维度的衔接

既有综述中的维度不需要废弃，而应重新放到“渠道、评分或比较字段”的正确层级，避免把标签、方向和权重混成同一组分数。

| 既有候选维度 | 新方案中的位置 | 处理方式 |
|---|---|---|
| 市场定位倾向 | 市场托底与政策定位渠道 | 对具体措施和期限判断方向、强度 |
| 制度变革确定性 | 执行确定性评分 | 不单独作为方向因子，作为关系幅度和状态权重 |
| 资金通道强度 | 增量资金与配置需求、制度开放与市场可达性渠道 | 根据具体机制分别保存 |
| 监管约束强度 | 监管约束与风险承担渠道 | 允许短期负向，并与长期治理改善拆开 |
| 政策边际变化 | 历史比较字段 | 有上一版政策或前一状态时评分，否则为`null` |
| 政策信息增量 | 信息增量评分 | 进入`NewsScore`，不等同于政策强度 |
| 风险偏好/EPU | 监管约束、不确定性渠道的市场结果 | 可作为渠道分项或外部验证变量，不与全A净温度重复计分 |
| 成长价值、大小盘 | 风格子课题 | 不进入全A净温度，只通过共同事件编号连接 |

## 七、步骤2C：最小评分单元与期限拆分

最小评分单元定义为：

```text
政策措施 × 全市场传导渠道 × 影响期限
```

建议使用`relation_id`连接一项措施、一个渠道和一个期限。同一措施如果短期与长期方向相反，应生成两条记录。

### 7.1 期限分类

| 期限 | 建议定义 | 主要检验窗口 |
|---|---|---|
| 即时 | 1～5个交易日 | 公告冲击和风险偏好 |
| 短期 | 1～4周 | 资金、交易和监管冲击 |
| 中期 | 1～6个月 | 制度执行和配置行为 |
| 长期 | 6个月以上 | 市场质量和制度状态 |

期限是分类字段，不建议让LLM直接给出伪精确的影响天数。后续可根据事件研究把期限映射为半衰期。

## 八、统一评分标准

行业、风格和全A三套方案建议尽量共用评分字段，便于维护同一套标注代码本。全A关系层使用以下字段。

### 8.1 影响方向：`-1/0/+1`

| 取值 | 定义 |
|---:|---|
| `+1` | 该渠道在当前期限内改善全A共同市场环境 |
| `0` | 原文明确信号中性，或当前关系内部正负大体抵消 |
| `-1` | 该渠道在当前期限内恶化全A共同市场环境 |
| `null` | 原文与必要背景不足，无法判断 |

`0`表示有证据的中性，`null`表示无信息，两者不能混用。

### 8.2 影响强度：`0～4`

| 分数 | 标准 |
|---:|---|
| 0 | 明确没有实质影响 |
| 1 | 原则性表态或很弱的工具变化 |
| 2 | 工具明确，但剂量、范围或市场影响有限 |
| 3 | 金额、比例、约束或制度变化较明确，可能产生可观察冲击 |
| 4 | 重大制度重构、大规模资金或强制性全国规则，可能改变市场均衡 |

强度只衡量政策工具力度，不重复计算覆盖范围和执行确定性。

### 8.3 覆盖范围：`0～4`

| 分数 | 标准 |
|---:|---|
| 0 | 明确不影响当前全A关系 |
| 1 | 极少数股票或单一局部板块 |
| 2 | 若干板块或一类市场主体 |
| 3 | 覆盖主要市场板块或多数上市公司 |
| 4 | 覆盖全市场交易、资金或治理环境 |

覆盖小于2的关系原则上不进入全A主因子，可保留在底表并转给行业或风格管线。

### 8.4 执行确定性：`0～4`

| 分数 | 标准 |
|---:|---|
| 0 | 讨论、研究或无法确认的表态 |
| 1 | 正式定调或原则意见，但没有工具和时间 |
| 2 | 工具已公布，关键细则或资金安排待定 |
| 3 | 对象、工具、部门和时间大部分明确 |
| 4 | 已生效或具备完整规则、流程、资金和监督安排 |

### 8.5 信息增量：`0～4`

| 分数 | 标准 |
|---:|---|
| 0 | 完全重复已知信息 |
| 1 | 主要复述，仅有措辞或程序变化 |
| 2 | 增加部分时间、范围或操作细节 |
| 3 | 新增工具、金额、适用范围或重要规则 |
| 4 | 政策框架或约束机制发生此前未知的重大变化 |

信息增量必须有历史比较文本。没有上一版规则、既有政策摘要或前一窗口状态时输出`null`，不能只凭当前文本猜测“超预期”。

### 8.6 政策边际变化：`-2～+2`

边际变化描述当前措施相对上一版政策、上一窗口状态或既有制度是加码还是退坡。它是历史比较字段，不是仅凭当前一篇文本可以完成的抽取。

| 分数 | 标准 |
|---:|---|
| +2 | 明显扩大支持、降低约束或由限制转为支持 |
| +1 | 小幅加码、扩大范围或补足关键细则 |
| 0 | 基本延续，实质政策状态没有变化 |
| -1 | 支持退坡、条件趋严或执行力度下降 |
| -2 | 明显收紧、取消支持或发生负向转向 |

没有可靠比较基准时输出`null`并标记“缺少历史基准”。边际变化可以独立检验，也可以作为政策状态分的差分，不建议未经验证直接重复乘入总分。

### 8.7 持续性：`0～4`

| 分数 | 标准 |
|---:|---|
| 0 | 一次性信息，不形成持续市场状态 |
| 1 | 原则上少于1个月 |
| 2 | 1～6个月 |
| 3 | 6个月至3年 |
| 4 | 长期制度性影响或无明确终止期 |

### 8.8 信息影响力：`0～4`

信息影响力用于来源和聚合加权，不表示政策方向。

| 分数 | 标准 |
|---:|---|
| 0 | 来源不明、内容无法核验 |
| 1 | 一般媒体转述或低层级局部信息 |
| 2 | 权威媒体报道、区域或单一部门信息 |
| 3 | 部委、交易所正式文件或全国性权威通稿 |
| 4 | 国家级重大文件、国务院或核心监管制度正式发布 |

### 8.9 AI置信度：`0～1`

置信度衡量抽取和关系判断是否可靠，不是政策影响强弱。每个分数必须同时保存`evidence`、`reason`、`confidence`和`missing_reason`。置信度低于0.70、需要三步以上推断或存在明显反向作用时进入人工复核。

## 十、事件级分数与日期聚合

### 10.1 基础事件分数

设：

- $d$：方向，取值`-1/0/+1`；
- $I$：影响强度，取值`0～4`；
- $C$：覆盖范围，取值`0～4`；
- $E$：执行确定性，取值`0～4`；
- $N$：信息增量，取值`0～4`；
- $Q$：信息影响力，取值`0～4`；
- $Conf$：AI置信度，取值`0～1`。

第一版建议同时保留“政策状态”和“新增政策冲击”两类分数。

政策状态分数：

$$
StateScore_r=d_r\times\frac{I_r}{4}\times\frac{C_r}{4}\times\frac{E_r}{4}\times\frac{Q_r}{4}\times Conf_r
$$

新增政策冲击分数：

$$
NewsScore_r=StateScore_r\times\frac{N_r}{4}
$$

- `StateScore`描述当前仍在生效的政策环境；
- `NewsScore`描述本次发布相对既有信息的新增冲击；
- 一项长期强政策即使信息增量已衰减，状态分数仍可保留；
- 乘法公式只是baseline，应与加法、分档和机器学习合成比较。

### 10.2 时间衰减

从市场可交易的$t_0$开始，按期限和持续性映射半衰期：

$$
Signal_{r,t}=Score_r\times 2^{-\frac{t-t_0}{HalfLife_r}}
$$

第一版可并行保留两套口径：

- 日频半衰期：5、20、60、120个交易日；
- 周频阶梯：事件周100%，随后75%、50%、25%，对应4/3/2/1衰减。

半衰期不由LLM自由生成，而由期限分类、政策类型和历史事件研究共同确定。

### 10.3 同日聚合

对于日期$t$和渠道$c$：

$$
Positive_{t,c}=\sum_r\max(Signal_{r,t,c},0)
$$

$$
Negative_{t,c}=\sum_r\min(Signal_{r,t,c},0)
$$

$$
Net_{t,c}=Positive_{t,c}+Negative_{t,c}
$$

全A净温度为各渠道净值的待检验合成：

$$
AllA\_Temperature_t=\sum_c w_c\times Net_{t,c}
$$

### 10.4 不建议只保存一个总分

第一版至少保留以下日期指标：

| 指标 | 含义 |
|---|---|
| `all_a_positive` | 当日仍有效的正向政策信号总量 |
| `all_a_negative` | 当日仍有效的负向政策信号总量 |
| `all_a_net_temperature` | 正负相加后的全A政策温度 |
| `all_a_news_shock` | 只强调信息增量的政策冲击 |
| `policy_disagreement` | 同日正负渠道并存程度 |
| `policy_attention` | 有效政策数量与信息影响力 |
| `weighted_certainty` | 加权执行确定性 |
| `weighted_novelty` | 加权信息增量 |
| `channel_*` | 八类渠道各自的正、负、净分 |
| `short_term_temperature` | 即时和短期关系聚合 |
| `medium_long_temperature` | 中长期关系聚合 |

## 十一、重复文本、同源事件与上限控制

政策原文、新闻通稿、媒体转载和卖方解读很容易重复放大。建议采用以下规则：

1. 同一文件不同转载只保留最早可获得时间和最高权威原文；
2. 同一事件不同官方文件可分别入库，但用`event_group_id`连接；
3. 征求意见、正式发布、配套细则属于不同信息阶段，不直接删除，但分别计算信息增量；
4. 同一事件、同一渠道、同一方向可比较`max`、`mean`、封顶求和和置信度加权；
5. 卖方解读只作为预期和传播层补充，不与官方原文等权相加；
6. 对单一事件设置渠道内贡献上限，避免长文件因拆出更多措施而机械获得更高权重。

## 十三、LLM任务、推断边界与JSON输出

### 13.1 三级信息边界

- 人工：复核低置信度、长传导链、短长期反向关系和历史比较字段；
- 程序：去重、连接长表、计算分数、时间衰减、聚合和版本管理。

### 13.4 Prompt关键规则

```text
你是资本市场政策文本标注员。你的任务是把单篇政策文本转成可回测的全A事件级结构化数据，不直接预测股票涨跌。

1. 先拆政策措施，再判断每项措施是否改变多数A股共同面对的资金、交易、治理或风险环境。
2. 只影响单一产业的关系转入行业管线；只影响不同股票特征相对收益的关系转入风格管线。
3. 全A最小评分单元为“政策措施 × 全市场传导渠道 × 影响期限”。
4. 同一措施存在多个渠道时分别输出；短期和长期方向相反时分别输出。
5. 先摘录原文证据，再给分；不得用原文外事实补足缺失字段。
6. 方向使用-1/0/+1；无信息输出null，不能用0代替。
7. 强度、覆盖、执行确定性、信息增量、持续性和信息影响力按0～4评分；政策边际变化按-2～+2评分。
8. 信息增量和政策边际变化必须有历史比较基准；没有基准时输出null和缺失原因。
9. 官方积极措辞不等于强正向，必须有工具、对象、金额、比例、期限或可执行规则。
10. 每条关系输出证据、因果链、反向作用、理由、置信度和人工复核标记。
11. L3市场表现推断必须标记needs_backtest=true，不能写成已成立事实。
12. 仅输出符合Schema的JSON。
```

## 十四、质量控制与人工复核

优先复核以下情况：

- AI置信度低于0.70；
- 一项措施产生四个以上全市场渠道；
- 覆盖小于2却进入全A主因子；
- 没有原文证据仍给出高分；
- 强度为4但没有重大金额、比例、强制规则或制度重构；
- 信息增量没有历史比较基准；
- 同一措施短期和长期可能方向相反但只输出一条关系；
- 把行业利好直接扩大为全A利好；
- 把小盘、成长等相对信号错误写入全A净温度；
- 把`null`错误填成0；
- 同一事件的转载和解读重复累计。

模型效果至少从三层验证：

1. 抽取准确性：措施、日期、金额、覆盖和渠道是否正确；
2. 评分一致性：人工—AI一致性、跨模型稳定性、重复运行稳定性；
3. 因子有效性：事件窗、方向命中、时序相关、分档收益、仓位回测和样本外稳定性。

## 十五、实证检验方案

### 15.1 事件研究

| 项目 | 建议口径 |
|---|---|
| 事件日 | 市场首次可交易日 |
| 市场基准 | 中证全指、万得全A；沪深300作为稳健性对照 |
| 窗口 | 1、3、5、10、20、60个交易日 |
| 事件分组 | 正/中/负；强/弱；渠道；确定性；信息增量；短期/长期 |
| 主要指标 | 指数收益、波动率、成交额、换手率、风险溢价代理变量 |
| 去重 | 同一事件组只保留一项主事件或设置聚类标准误 |

事件研究只能说明政策发布后市场表现是否存在统计差异，不能自动证明因果。需控制同期宏观冲击、货币政策、海外市场和重大行业事件。

### 15.2 时序因子检验

由于全A因子在单日只有一个时间序列，不适合照搬个股横截面IC作为主检验。建议重点使用：

- 因子与未来1、5、20、60日全A收益的时序相关；
- 因子分位数或正负档位下的未来收益、波动和回撤；
- Newey-West或其他时序稳健标准误；
- 滚动窗口稳定性和分阶段结果；
- 加入估值、趋势、波动、流动性、货币条件后的增量预测检验；
- 样本内选参数、样本外固定参数，避免用全样本寻找最优半衰期。

### 15.3 仓位映射回测

第一版先使用简单、可解释的分档映射，不直接训练复杂模型：

| 全A净温度 | 示例仓位档位 |
|---:|---:|
| 高正向 | 100% |
| 温和正向 | 75% |
| 中性 | 50% |
| 温和负向 | 25% |
| 高负向 | 0% |

正式回测需披露交易成本、调仓频率、空仓资产收益、最大回撤、年化收益、波动率、夏普比率和相对全A基准表现。仓位阈值只能由训练样本确定，不能看完测试集再调整。

### 15.4 对照组与稳健性

- 仅文本净情绪；
- 仅官方政策数量；
- 不拆措施的一篇一分法；
- 拆措施但不拆渠道；
- 不区分短期与长期；
- 等权、信息影响力加权、置信度加权；
- 日频半衰期与周频4/3/2/1衰减；
- 仅官方原文与“官方+权威媒体”两种文本池；
- 剔除货币政策、行业政策和卖方解读后的纯资本市场样本。

### 16.1 第一版必做字段

| 层级 | 必做内容 |
|---|---|
| 文件层 | 来源、首次公开时间、文件阶段、政策层级、原文、去重组 |
| 措施层 | 措施摘要、政策动作、对象、生效时间、证据 |
| 路由层 | 全A相关性、覆盖层级、三条子课题路由 |
| 关系层 | 全市场渠道、期限、因果链、反向作用 |
| 评分层 | 方向、强度、覆盖、确定性、增量、边际变化、持续性、影响力 |

### 16.2 建议实施顺序

1. 冻结八类全市场渠道及边界；
2. 冻结方向、强度、覆盖、确定性、信息增量和持续性的评分锚点；
3. 建立全A—行业—风格路由规则；
4. 人工标注30～50篇代表性文本，覆盖稳市、资金入市、交易制度、再融资、减持、退市、执法和市场开放；
5. 比较AI与人工在措施拆分、路由、渠道和方向上的一致性；
6. 生成第一版事件长表，不急于合成唯一总分；
7. 并行构造等权、乘法、分档和渠道加权版本；
8. 完成事件研究与时序检验后，再确定半衰期、渠道权重和仓位映射；
9. 固定样本外方案，形成全A政策温度日频面板。

## 十七、当前局限

- 当前渠道体系和评分锚点是方法设计，不是已经验证的最优因子；
- 全A政策事件数量可能较少，复杂模型容易过拟合；
- 政策通常在市场预期中提前发酵，单纯使用发布日期可能低估预期阶段；
- 信息增量需要历史政策库和相似文本检索，单篇Prompt无法可靠完成；
- 短期价格冲击与长期制度价值可能方向相反，需要分期限保存；
- 政策往往与宏观、货币和市场下跌同时发生，反向因果和政策响应偏差较强；
- 全A因子是时间序列，不能用个股横截面IC替代主要验证；
- LLM置信度只能衡量标注可靠性，不能作为政策有效性的证据。

## 十八、当前结论

全A直接打分方向可以与行业、风格方案共用同一套事件数据库母框架，但应保留自己的观察对象：

```text
政策文件表
→ 政策措施表
→ 全A路由表
→ 措施—全市场渠道—期限关系表
→ 关系评分表
→ 日期—渠道聚合表
→ 全A政策因子面板
→ 经样本外检验后的仓位信号
```

第一版最重要的不是立即确定一个“全A总分”，而是先把措施、渠道、期限、正负方向和证据保存完整。最终净温度只是其中一个聚合结果；正向政策量、负向政策量、政策分歧、信息增量、渠道分项和短中长期信号同样需要保留。这样既能与行业、风格方案衔接，也为后续回测选择权重和时间参数留下空间。
